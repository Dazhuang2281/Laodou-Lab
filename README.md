# 拼豆图纸生成器

![拼豆图纸生成器](docs/screenshot.png) <!-- 如果你有截图，可以替换为实际路径 -->

一个完全基于浏览器的拼豆（Perler Bead）图纸生成工具。上传任意图片，即可自动生成高清像素图纸，支持自定义尺寸、颜色优化和手动涂色编辑，无需后端，隐私安全。

## ✨ 功能特性

- **图片上传**：支持 JPG、PNG、GIF 格式，拖拽或点击上传。
- **智能像素化**：
  - 基于 **CIE Lab 颜色空间** 进行颜色匹配，更符合人眼感知。
  - 自动后处理：清理稀有颜色、合并相似色、限制颜色数量，使图纸整洁清晰。
  - 可选边缘增强（Sobel 算子），突出线条轮廓。
- **灵活尺寸**：自定义宽度（1-100 格），高度按原图比例自动计算。
- **实时预览**：三种视图模式：像素预览、网格标注（带色号）、原图对比。
- **手动涂色**：点击下方色板选择颜色，再点击预览图格子即可自由编辑，实现手绘般的精细调整。
- **图纸导出**：一键下载 PNG 格式图纸，方便打印或参考。

## 🛠️ 技术栈

- **前端**：HTML5、CSS3、原生 JavaScript (ES6 模块)
- **图像处理**：Canvas API、CIE Lab 色彩转换、中位切分量化、Floyd‑Steinberg 抖动（可选）
- **算法核心**：模块化 `pindou-core.js`，包含颜色匹配、边缘检测、后处理等

## 📖 使用指南

### 基础流程
1. **上传图片**：点击上传区域或拖拽图片。
2. **设置尺寸**：在“自定义宽度”输入框中填写目标格子数（1-100）。
3. **调整参数**（可选）：
   - 对比度增强：滑杆调节强度，0.8 减弱，1.5 增强。
   - 边缘增强：勾选后可用滑杆控制强度，适合线条简单的图案。
   - 显示选项：可切换显示网格线或颜色编号。
4. **生成图纸**：点击“生成拼豆图纸”按钮，稍等片刻即可在右侧预览。
5. **下载**：满意后点击“下载图纸”保存 PNG 文件。

### 手动涂色
- 生成图纸后，下方会显示完整的色板（每个色块标注了颜色编号，如 P01）。
- 点击色块选中颜色（色块边框变黑），此时鼠标变为十字准星。
- 点击预览图中的任意格子，该格子即变为选中颜色。
- 按 `ESC` 键可退出涂色模式。

### 裁剪图片
如需裁剪，点击“裁剪图片”按钮，在弹出框中拖动选框调整区域，确认后自动重新生成。

## ⚙️ 参数说明

| 参数 | 范围 | 说明 |
|------|------|------|
| 自定义宽度 | 1-100 | 输出图纸的横向格子数，高度自动按比例计算。 |
| 对比度增强 | 0.8-1.5 | 1.0 为原始，小于 1.0 减弱，大于 1.0 增强。 |
| 边缘增强 | 0-1.5 | 勾选后生效，数值越大边缘越突出，适合线条明显的图像。 |
| 显示网格线 | 开/关 | 在网格视图下显示格子边界线。 |
| 显示颜色编号 | 开/关 | 在网格视图下每个格子内显示颜色代码（如 P01）。 |

## 🧠 核心算法概述

所有图像处理逻辑均封装在 `pindou-core.js` 中，主要步骤包括：

1. **预处理**：可选边缘增强（Scharr 算子）和对比度调整。
2. **颜色量化**：将 RGB 转换到 Lab 空间，通过加权欧氏距离匹配预定义的 45 色 Perler 色板。
3. **后处理**：
   - 清理稀有颜色（出现比例 <0.3% 的色块映射到最近邻）。
   - 相似颜色合并（基于 Lab 距离阈值自动估算）。
   - 限制最大颜色数量（根据图像复杂度自动估算）。
4. **输出**：生成像素数据矩阵和对应的颜色索引网格。
